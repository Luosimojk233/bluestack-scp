SCP: SECRET LABORATORY

蓝栈 SCP：秘密实验室

BlueStack SCP: Secret Laboratory

欢迎来到蓝栈服务器！我们在保留 SCP:SL 核心玩法的基础上， 加入状态栏、积分系统、MVP、全局消息和中途加入等功能， 致力于为所有玩家提供稳定、友好且有趣的游戏环境。

服务器规则 服务器功能 积分规则 胜利奖励 常用指令 联系方式

服务器规则 SERVER RULES

  1. 禁止使用外挂、脚本或其他未经允许的作弊工具。
  2. 禁止恶意利用游戏漏洞或 Bug 获取不公平优势。
  3. 禁止恶意友军伤害、恶意击杀队友以及故意破坏阵营行动。
  4. 禁止辱骂、骚扰、歧视、威胁或针对其他玩家。
  5. 禁止刷屏以及滥用全局消息功能发布违规内容。
  6. 请配合管理员进行合理的调查与处理。
管理员会根据违规情节采取警告、禁言、踢出或封禁等措施。 请共同维护良好的服务器环境。

服务器功能 SERVER FEATURES

  • 无限体力 玩家可以持续奔跑，无需等待体力恢复。
  • 无限备用弹药 枪械拥有无限备用弹药，弹匣仍需正常更换。
  • 支持中途加入与自动重生 回合进行中加入服务器时，系统会根据当前情况匹配合适角色并安排重生。
  • D级人员出生物品 D级人员出生时额外获得一个硬币和一个止痛药。
  • 实时状态栏 显示玩家名称、身份、延迟、积分、今日在线时间和存活人数。
  • 积分、助攻与本局 MVP 自动统计击杀、助攻、胜利奖励和本回合优秀玩家。
  • 全局玩家消息 玩家可以通过客户端控制台向全服发送排队消息。

积分获取与扣除 SCORE SYSTEM

新玩家初始积分 10 分

首次加入积分系统时自动初始化。

普通敌对击杀 +10

有效击杀其他敌对人类阵营成员。

击杀 SCP +15

完成对 SCP 角色的有效击杀。

SCP 击杀人类 +5

SCP 有效击杀非 SCP 玩家。

D级有效击杀 额外 +1

D级人员完成有效敌对击杀时获得额外奖励。

有效助攻 +3

在目标死亡前 60 秒内造成过伤害，且不是最终击杀者。

普通死亡 -5

被敌对玩家正常击杀。

自杀或环境死亡 -5

主动自杀或因环境伤害死亡。

被友军击杀 不扣分

被队友击杀的受害者不会失去积分。

友军击杀 不加分

不获得积分，也不会计入有效击杀数量。

积分最低为 0，不会出现负数。同一名玩家对同一目标造成多次伤害， 最终只计算一次助攻。

胜利奖励 VICTORY REWARDS

基金会阵营胜利 +20

仅奖励胜利时仍然存活的基金会阵营成员。

混沌阵营胜利 +20

仅奖励胜利时仍然存活的混沌阵营成员。

SCP 阵营胜利 +30

仅奖励胜利时仍然存活的 SCP。

人类核爆胜利 额外 +5

符合条件的人类胜利阵营获得核爆额外奖励。

只有胜利阵营中仍然存活的玩家可以获得胜利积分。 多个主要敌对阵营同时存活或无法判断胜方时，不发放胜利积分。

友军关系 FRIENDLY FACTIONS

基金会阵营

基金会武装、设施警卫与科学家互为友军。

混沌阵营

混沌分裂者与D级人员互为友军。

SCP 阵营

所有 SCP 角色之间互为友军。

友军伤害不会被记录为有效助攻，友军击杀也不会获得积分。

本局 MVP ROUND MVP

表现积分 MVP

根据本回合通过有效击杀和助攻获得的积分计算。 胜利积分与管理员调整不参与计算。

最多击杀 MVP

根据本回合有效击杀数量计算，成绩相同的玩家可以并列获奖。

常用指令 PLAYER COMMANDS

.bc 内容

向全服发送一条消息。每条展示 5 秒，每名玩家独立冷却 10 秒。 多条消息会按照提交顺序排队展示。

.zs

立即结束当前角色。成功执行后会按普通死亡规则扣除积分。

.sc

开启或关闭游戏画面底部的实时状态栏。

按下 ~ 打开游戏客户端控制台后输入指令。 指令前必须带英文句点，例如 .sc，不是 /sc。
