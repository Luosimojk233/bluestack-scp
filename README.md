## 🎮 服务器功能

- 无限体力
- 无限备用弹药
- 支持中途加入

- 本局最多击杀 MVP
- 玩家全局消息队列

## 📊 积分规则

| 行为 | 积分变化 |
|---|---:|
| 新玩家初始积分 | 10 |
| 普通敌对击杀 | +10 |
| 击杀 SCP | +15 |
| SCP 击杀人类 | +5 |
| D级人员有效击杀 | 额外 +1 |
| 有效助攻 | +3 |
| 普通死亡 | -5 |
| 自杀或环境死亡 | -5 |
| 被友军击杀 | 不扣分 |
| 友军击杀 | 不加分 |
| 基金会阵营胜利 | 存活成员 +20 |
| 混沌阵营胜利 | 存活成员 +20 |
| SCP 阵营胜利 | 存活 SCP +30 |
| 人类核爆胜利 | 额外 +5 |

积分最低为 `0`，不会出现负数。

---

## 🏆 本局 MVP

回合结束时会统计：

- **表现积分 MVP**：根据本回合有效击杀和助攻获得的积分计算
- **最多击杀 MVP**：根据本回合有效击杀数量计算

胜利积分和管理员调整的积分不参与表现积分 MVP 计算。

## ⌨️ 玩家指令

玩家按 `~` 打开游戏客户端控制台，然后输入：

| 指令 | 功能 |
|---|---|
| `.bc 内容` | 向全服排队发送消息 |
| `.zs` | 当前角色自杀 |
| `.sc` | 开启或关闭底部状态栏 |

### 全局消息规则

- 每条消息显示 5 秒
- 每名玩家独立冷却 10 秒
- 多条消息按照提交顺序排队
- 必须等待上一条消息消失后才显示下一条
